# Plant Disease Detection Web Application

A deep learning web application built with Python, Flask, and TensorFlow/Keras to detect plant leaf diseases.

## Model Weights
Due to GitHub file size limits, download the trained model file (203 MB) here:
[Download Model Weights File](https://drive.google.com/file/d/1b3Hu9IbH1DmNUHC2qBe_y2gxO8Xzqtv0/view?usp=sharing)

Place the .keras file in the root directory before running python app.py.
